# reco — 本地小说推荐程序

独立项目。用户把作品按目录放入：

```
<数据根>/            # 默认 F:\date\adult-reco\data
├── liked/          # 我喜欢的
├── candidate/      # 候选池
└── 推荐专区/        # 程序输出
```

程序按口味给候选池打分排序；点「不合口味」积累负样本；口味画像可见、可编辑。
同时提供 PyQt6 桌面 GUI 与无界面 CLI，两者共用同一套算法。

## 状态

- 骨架初始化中；架构文档见 `docs/ARCHITECTURE.md`（由架构师产出，人审后生效）。
- 工具链：Python 3.12（DSH 自带解释器）+ `.venv`；不依赖任何外部项目。

## 数据与数据库

- **唯一运行数据库 = 仓库根 `reco.db`**；`*.db` 已在 `.gitignore`，仓库不跟踪任何数据库文件。
- `packages/` 下不得存放数据库副本。历史 `packages/reco.db` 旧副本只存在于本地、未被跟踪；
  旧副本归档区约定为 `.scratch/archive/`（`.scratch/` 为不入库的本地草稿区，见 #45/#49）。

## 约束

- 程序内部可计算正文统计量，但正文不得出现在日志、报告、commit、对话中。
- 不做硬排除；唯一硬过滤是去重。
- 标签与人物关系是数据，不是代码常量。
